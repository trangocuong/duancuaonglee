# LOTID 자리 규칙 — 사용자 확인 2026-09-24

| 자리(1부터) | 의미 |
|---|---|
| 1 | 사이트. H는 HYV. 다른 사이트 생산 반제품·반품 등은 다른 값 가능 |
| 2~4 | LOTID 임의 구분값 |
| 5~7 | Split 시 구분값 |
| 8 | 연도 마지막 숫자. 단독으로 연대 확정 불가 |
| 9~10 | ISO 주차(ISOWEEKNUM) |

형식 설명용 예: H / ABC / 001 / 6 / 39. 실제 발생 번호가 아닌 가상 예시.

## 추가 확정 사항
- 5~7자리 `000`은 SMT 투입 RUNID를 뜻한다.
- Split 구분값은 `001`~`ZZZ` 범위에서 부여되며, 중간에 부여 금지 값이 존재한다.
- 사용자 지시: 부여 금지 값의 목록·규칙은 미확정으로 남긴다. 이를 확정하기 위한 추가 질문은 보류한다.

## 검증 기준 및 남은 미확정 사항
- 번호가 건너뛴다는 이유만으로 누락·오류로 판정하지 않는다.
- 단순 연속 증가나 번호만으로 부모 LOT 관계를 확정하지 않는다. 실제 Split/Merge 이벤트와 RUNID 맵의 연결 근거를 확인한다.
- 증가 순서, 재분할 부여 규칙, 연도 자리와 ISO 주차의 연말 경계 기준도 아직 미확정이다.
- 이 문서는 검증 기준 기록이다. 아래 재현 결과는 수정 전 1.0.1 기준이다. 1.0.2는 번호 순서만으로 부모를 추정하는 동작을 제거했다.

로컬 1.0.1 Windows 및 HTML 엔진 재현 결과:
- 임의 구분값·연도·주차가 달라도 한 자리의 1,2,3 패턴과 수량 조건으로 부모를 추정함.
- 예: H1AB000639 / H2AB000639 / H3AB000639 → H0AB000639 추정. 자리 규칙만으로는 이 관계를 확정할 근거가 없음.
- 현 검증은 합성 입력으로 수행. 실제 파일 계보 판정 검증과 구분한다.
- 1.0.1 조사 시점에는 엔진 및 배포물을 변경하지 않았다. 상세 재현은 check-lotid-position-20260924.mjs와 .log 참고.


## Split / Merge 의미 — 사용자 추가 확인
- Split: 분할로 1개 이상의 LOTID가 부여된다.
- Merge: 현재 LOTID의 수량이 대상 LOTID로 이동한다.
- Merge로 현재 LOTID의 수량이 전부 이동하면 현재 LOT은 Terminate 처리된다. 종료되는 것은 수량을 보낸 원래 LOT이며, 대상 LOT의 종료를 뜻하지 않는다.
- 일부 수량 이동만으로 원래 LOT이 Terminate되었다고 판단하지 않는다.
- 추적 시 보내는 LOT, 받는 LOT, 이동 수량, 원래 LOT의 잔량 및 종료 이력을 구분한다.
- Terminate 상태만으로 Merge 발생을 역추정하지 않는다. 이동 관계는 실제 이벤트·맵 근거로 확인한다.
- 1.0.2에서 Merge 표시 방향과 Split 이력 보존, 원래 LOT의 Terminated 상태 보존에 반영했다.
- 대상 LOT의 이력에도 Merge가 기록될 수 있다. 이 경우 대상 LOT 수량이 이동 수량만큼 증가하므로 1.0.3부터 이벤트 전후 수량으로 유입·유출을 판정한다.
- 상호 이벤트와 수량 흐름이 일치하지 않으면 방향을 확정하지 않고 `병합 방향 확인 필요`로 남긴다.

## 개발 방향 — 내부망 SQL 조회 연결을 전제로 설계
사용자가 확정한 요구사항:
- 현재는 사용자가 LOTID를 조회하고 내려받은 파일로 분석 규칙을 검증한다.
- 개발 및 분석 검증 완료 후에는 내부망 데이터베이스를 SQL로 조회하는 기능을 연결한다.
- 지금부터 이 전환을 고려하여 프로그램을 개발한다.

설계 기준:
- 파일 읽기 / 향후 SQL 조회의 데이터 수집 계층과 Split·Merge·수량·공정 분석 계층을 분리한다.
- 두 수집 방식은 공통 입력 구조로 변환하여 동일한 분석 엔진을 사용하도록 한다. 원본 이력과 맵의 역할은 구분한다.
- 파일 입력은 재현·회귀 검증 경로로 유지한다. SQL 조회 결과도 출처와 조회 조건을 추적할 수 있게 설계한다.
- DB 종류, 테이블/열, 조회 SQL, 권한 및 접속 방식은 연결 단계에서 확인한다. 현재 DB 연결 구현·운영 조회는 수행하지 않았다.
