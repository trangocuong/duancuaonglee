CSV / XLS / XLSX 파일을 여러 개 선택하세요. 일반 파일명은 LOTID로 사용하고, 보안 다운로드 UUID 파일명은 ASSYLOT·상호 Split 이력으로 실제 LOTID를 판별합니다. PCB 분할/병합 맵 파일과 RUNID CSV(LOT_ID/PROD_ID/MERGE_LOT 형식)도 함께 선택할 수 있습니다. 검증 기록 · 문제 재현용

분석을 실행할 때마다 진행 단계·사용한 파일 이름과 SHA-256 해시·오류 내용을 자동으로 기록합니다(이 탭을 열지 않아도 기록됩니다). 아래 버튼을 누르면 이번 브라우저 탭에서 실행한 모든 분석 기록과, 그중 최근 5회분의 원본 입력 파일 사본·결과물을 검증결과.zip 하나로 내려받습니다. SMT RUNID SMT/PMS 흐름이 검증되면 요약 행으로 집계하고, 개별 LOT·수량 원본은 검증 ZIP의 요약 JSON에서 확인할 수 있습니다. 문제가 생겼을 때 이 zip을 그대로 전달하면 어느 파일에서 무엇이 어떻게 처리됐는지 재현할 수 있습니다. 원본 파일은 수정되지 않으며, 이 zip도 다운로드 폴더 밖으로 자동 전송되지 않습니다.
